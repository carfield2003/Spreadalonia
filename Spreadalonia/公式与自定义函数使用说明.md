## 1. 概述

Spreadalonia 内置了一个完整的公式引擎，支持：

| 能力         | 说明                               |
| ---------- | -------------------------------- |
| **单元格引用**  | `=A1`、`=B2*C3`                   |
| **范围引用**   | `=SUM(A1:A10)`、`=AVERAGE(B2:D8)` |
| **内置函数**   | 数学/统计、逻辑、文本处理、信息判断共 22 个函数       |
| **自定义函数**  | 通过 `Register` 注册 C# 委托，在公式中直接调用  |
| **依赖追踪**   | 自动检测公式间的引用关系，数据变化时级联重算           |
| **循环引用检测** | 自动检测并报告循环引用错误                    |
| **错误隔离**   | 单个公式出错不影响其他单元格                   |

### 架构概览

```
 用户输入      解析       求值                 结果
 =SUM(A1:A2)  ───► AST ───► FunctionNode ───► FunctionRegistry.Call()
                                                       │
                                           ┌───────────┼───────────┐
                                           ▼                       ▼
                                    内置函数 (SUM)          自定义函数 (Register)
```

## 2. 快速入门：在表格中使用公式

### 2.1 输入公式

在单元格中输入以 `=` 开头的表达式即可：

```
=10 + 20           → 显示 30
=A1 + B1           → 显示 A1 和 B1 的和
=SUM(A1:A10)       → 显示 A1 到 A10 的和
=IF(A1>0, "正", "负")  → 根据条件显示不同文本
```

### 2.2 单元格引用

| 写法           | 含义                      |
| ------------ | ----------------------- |
| `A1`         | 引用 A 列第 1 行的单个单元格       |
| `A1:B5`      | 引用 A1 到 B5 的矩形区域（2列×5行） |
| `B2:B4`      | 引用 B2 到 B4 的单列范围        |
| `A1, A3, A5` | 用逗号分隔多个不连续的引用           |

### 2.3 运算符

| 运算符  | 功能     | 示例             |
| ---- | ------ | -------------- |
| `+`  | 加法     | `=A1 + B1`     |
| `-`  | 减法/负号  | `=A1 - B1`     |
| `*`  | 乘法     | `=A1 * 1.5`    |
| `/`  | 除法     | `=A1 / 12`     |
| `^`  | 幂运算    | `=A1 ^ 2`      |
| `()` | 分组/优先级 | `=(A1+A2)*0.1` |
| `&`  | 字符串连接  | `=A1 & "万元"`   |

### 2.4 比较运算和布尔值

比较运算的结果可以被 `IF`、`AND`、`OR` 等逻辑函数使用：

| 运算符  | 示例          |
| ---- | ----------- |
| `=`  | `=A1 = 100` |
| `<>` | `=A1 <> ""` |
| `>`  | `=B2 > 0`   |
| `<`  | `=B2 < 100` |
| `>=` | `=B2 >= 60` |
| `<=` | `=B2 <= 60` |

> **注意**：`TRUE` 和 `FALSE` 可以作为单元格的文本值直接输入（不区分大小写）。

## 3. 内置函数速查表

### 3.1 数学/统计函数

#### SUM(args...)

返回所有参数中数值的总和，自动忽略非数值。

```
=SUM(A1:A10)              → 求 A1 到 A10 的和
=SUM(1, 2, 3)             → 6
=SUM(A1, B2:B5, 100)      → 混合引用和常量的和
```

#### AVERAGE / AVG (args...)

返回所有数值参数的平均值。`AVG` 是 `AVERAGE` 的别名。

```
=AVERAGE(A1:A10)          → 求平均值
=AVERAGE(10, 20, 30)      → 20
```

#### COUNT(args...)

统计参数中数值的个数。

```
=COUNT(A1:A10)            → 统计有多少个数字
```

#### COUNTA(args...)

统计参数中非空值的个数（包括文本）。

```
=COUNTA(A1:A10)           → 统计有多少个非空单元格
```

#### MAX(args...)

返回数值参数中的最大值。

```
=MAX(A1:A10)              → 返回最大值
=MAX(10, B2, C3)          → 返回最大值
```

#### MIN(args...)

返回数值参数中的最小值。

```
=MIN(A1:A10)              → 返回最小值
```

#### ABS(number)

返回绝对值。

```
=ABS(-5)                  → 5
=ABS(A1)                  → A1 的绝对值
```

#### ROUND(number, digits?)

四舍五入到指定小数位。digits 默认为 0。

```
=ROUND(3.14159, 2)        → 3.14
=ROUND(A1, 0)             → 四舍五入到整数
```

#### SQRT(number)

返回平方根。参数必须 ≥ 0。

```
=SQRT(16)                 → 4
=SQRT(A1)                 → A1 的平方根
```

#### POWER(base, exponent)

返回 base 的 exponent 次幂。

```
=POWER(2, 10)             → 1024
=POWER(A1, 2)             → A1 的平方
```

### 3.2 逻辑函数

#### IF(condition, trueValue, falseValue?)

条件判断。如果第三个参数省略，条件为假时返回 0。

```
=IF(A1 > 60, "及格", "不及格")
=IF(B2 > 0, B2 * 1.1, B2)
```

#### AND(args...)

所有参数都为真时返回 TRUE。

```
=AND(A1 > 0, B1 > 0)      → 两个都大于 0 时为 TRUE
```

#### OR(args...)

任一参数为真时返回 TRUE。

```
=OR(A1 = "是", A1 = "YES")
```

#### NOT(value)

取反。

```
=NOT(A1 = 0)              → A1 不为 0 时为 TRUE
```

### 3.3 文本函数

#### CONCAT / CONCATENATE(args...)

连接所有参数为字符串。

```
=CONCAT("Hello", " ", "World")    → "Hello World"
=CONCAT(A1, "号订单")             → A1的内容 + "号订单"
```

#### UPPER(text)

转大写。

```
=UPPER("hello")           → "HELLO"
=UPPER(A1)
```

#### LOWER(text)

转小写。

```
=LOWER("HELLO")           → "hello"
```

#### TRIM(text)

去除首尾空格。

```
=TRIM("  hello  ")        → "hello"
```

#### LEN(text)

返回字符串长度（字符数）。

```
=LEN("hello")             → 5
=LEN(A1)
```

#### LEFT(text, count?)

从左边取子串。count 默认为 1。

```
=LEFT("hello", 2)         → "he"
=LEFT(A1, 3)
```

#### RIGHT(text, count?)

从右边取子串。count 默认为 1。

```
=RIGHT("hello", 2)        → "lo"
```

#### MID(text, start, count)

从指定位置取子串。start 从 1 开始计数。

```
=MID("hello", 2, 3)       → "ell"
=MID(A1, 1, 5)
```

### 3.4 信息函数

#### ISBLANK(value)

如果值为空/空白则返回 TRUE。

```
=ISBLANK(A1)              → A1 为空时为 TRUE
=IF(ISBLANK(A1), "待填写", A1)
```

#### ISNUMBER(value)

如果值是数字则返回 TRUE。

```
=ISNUMBER(A1)             → A1 为数字时为 TRUE
```

#### ISTEXT(value)

如果值是字符串则返回 TRUE。

```
=ISTEXT(A1)               → A1 为文本时为 TRUE
```

### 3.5 查找函数（受限支持）

#### VLOOKUP / HLOOKUP

> 这两个函数目前仅支持有限场景，完整的范围查找尚未实现。建议使用自定义函数代替复杂的查找逻辑。

## 4. 公式语法参考

### 4.1 完整语法规则

```
表达式     := 比较表达式
比较表达式  := 加减表达式 (比较运算符 加减表达式)?
加减表达式  := 乘除表达式 (('+' | '-') 乘除表达式)*
乘除表达式  := 幂表达式 (('*' | '/') 幂表达式)*
幂表达式   := 一元表达式 ('^' 幂表达式)?
一元表达式  := ('+' | '-')? 基本表达式
基本表达式  := 数字 | 字符串 | 布尔值 | 单元格引用 | 函数调用 | '(' 表达式 ')'

函数调用   := 函数名 '(' 参数列表? ')'
参数列表   := 表达式 (',' 表达式)*

单元格引用  := 列字母 行号           (如 A1)
范围引用   := 单元格引用 ':' 单元格引用  (如 A1:B5)
```

### 4.2 数据类型与转换规则

| 输入               | 识别为 | CachedValue 类型 |
| ---------------- | --- | -------------- |
| `123`            | 数字  | `double`       |
| `3.14`           | 数字  | `double`       |
| `hello`          | 字符串 | `string`       |
| `TRUE` / `FALSE` | 布尔  | `bool`         |
| `=SUM(...)`      | 公式  | 计算结果类型         |

**自动转换**：公式引擎在需要时会自动转换类型。例如 `SUM` 中的文本数字会被转为数值，逻辑函数中 `0` 被视为 `FALSE`。

## 5. 注册自定义函数

这是自定义函数的核心功能——让你可以将 C# 方法绑定到表格公式中。

### 5.1 获取入口

```csharp
// spreadSheet 是你的 Spreadsheet 控件实例
var functions = spreadSheet.FormulaEngine.Functions;
```

或者通过 `FormulaEngine` 间接访问其 `Functions` 属性。

### 5.2 方式一：简单注册（仅接收参数）

适用于只需要传入参数、返回结果的场景。

**签名**：`Register(string name, Func<List<object>, object> func)`

```csharp
// 示例 1：翻倍函数
spreadSheet.FormulaEngine.Functions.Register("DOUBLE", args =>
{
    if (args.Count < 1) throw new Exception("需要一个参数");
    return Convert.ToDouble(args[0]) * 2;
});

// 示例 2：计算 BMI
spreadSheet.FormulaEngine.Functions.Register("BMI", args =>
{
    double weight = Convert.ToDouble(args[0]);   // 体重 kg
    double height = Convert.ToDouble(args[1]);   // 身高 m
    return weight / (height * height);
});

// 示例 3：税费计算（从数据库查税率）
spreadSheet.FormulaEngine.Functions.Register("TAX", args =>
{
    double amount = Convert.ToDouble(args[0]);
    string category = args[1]?.ToString() ?? "default";
    // 调用你的业务逻辑
    double rate = MyTaxService.GetRate(category);
    return amount * rate;
});
```

**表格中使用**：

```
=DOUBLE(A1)
=BMI(B2, B3)
=TAX(A1, "电子产品")
```

### 5.3 方式二：上下文注册（推荐，功能更强）

适用于需要知道公式所在位置、读取其他单元格值的场景。

**签名**：`Register(string name, Func<CustomFunctionContext, object> func)`

**`CustomFunctionContext` 可用成员**：

| 成员                       | 类型                        | 说明               |
| ------------------------ | ------------------------- | ---------------- |
| `Args`                   | `IReadOnlyList<object>`   | 已求值的参数列表         |
| `Column`                 | `int`                     | 公式所在列索引（0-based） |
| `Row`                    | `int`                     | 公式所在行索引（0-based） |
| `Cell`                   | `(int Col, int Row)`      | 公式所在单元格坐标        |
| `GetCellValue(col, row)` | `Func<int, int, object>`  | 读取任意单元格的已求值      |
| `GetValue("A1")`         | `object GetValue(string)` | 按名称读取单元格值        |

```csharp
// 示例 1：加权求和（权重从第一行读取）
spreadSheet.FormulaEngine.Functions.Register("WEIGHTED_SUM", ctx =>
{
    // 参数：数据单元格范围
    // 权重从同一行的第一个单元格（A列）读取
    double sum = 0;
    double weight = Convert.ToDouble(ctx.GetCellValue(0, ctx.Row) ?? 1.0);

    foreach (var arg in ctx.Args)
    {
        if (arg != null && double.TryParse(arg.ToString(), out double val))
            sum += val * weight;
    }
    return sum;
});

// 示例 2：动态汇率换算（汇率从固定配置单元格读取）
spreadSheet.FormulaEngine.Functions.Register("USD2CNY", ctx =>
{
    // 从 E1 读取汇率（可让用户自行修改）
    double rate = Convert.ToDouble(ctx.GetValue("E1") ?? 7.2);
    double usd = Convert.ToDouble(ctx.Args[0]);
    return Math.Round(usd * rate, 2);
});

// 示例 3：条件聚合（读取表格配置+统计范围）
spreadSheet.FormulaEngine.Functions.Register("CONDITIONAL_SUM", ctx =>
{
    string col = ctx.Args[0]?.ToString();      // 列字母，如 "B"
    double threshold = Convert.ToDouble(ctx.Args[1]);

    // 从配置单元格读取参数
    double vatRate = Convert.ToDouble(ctx.GetValue("D1") ?? 0.13);

    double sum = 0;
    // 遍历该列的所有行...（具体实现取决于你的需求）
    return sum;
});
```

### 5.4 两种方式的区别

|             | 简单注册  | 上下文注册                |
| ----------- | ----- | -------------------- |
| 拿到参数值       | ✅     | ✅                    |
| 知道是哪个单元格在调用 | ❌     | ✅                    |
| 读取其他单元格的值   | ❌     | ✅                    |
| 按名称读取单元格    | ❌     | ✅ (`GetValue("A1")`) |
| 适用场景        | 纯计算函数 | 需要上下文判断的函数           |

### 5.5 覆盖内置函数

你可以用同名的自定义函数覆盖内置函数：

```csharp
// 用你自己的 SUM 替换内置的 SUM
spreadSheet.FormulaEngine.Functions.Register("SUM", args =>
{
    // 你的自定义实现...
    double sum = 0;
    foreach (var arg in args)
    {
        if (arg is double d) sum += d;
    }
    return sum;
});
```

### 5.6 注销/查询函数

```csharp
// 检查某个函数是否已注册
bool exists = spreadSheet.FormulaEngine.Functions.IsRegistered("MYFUNC");

// 重新注册即可覆盖（同名后注册的会覆盖之前的）
spreadSheet.FormulaEngine.Functions.Register("MYFUNC", args => /* ... */);
```

## 6. 编程方式操作数据与公式

### 6.1 批量设置数据：SetData

```csharp
// 接受 IEnumerable<KeyValuePair<(int col, int row), string>>
// 其中 col 和 row 都是 0-based

var data = new Dictionary<(int, int), string>
{
    { (0, 0), "产品名称" },      // A1
    { (1, 0), "单价" },          // B1
    { (2, 0), "数量" },          // C1
    { (3, 0), "小计" },          // D1
    { (1, 1), "100" },           // B2
    { (2, 1), "5" },             // C2
    { (3, 1), "=B2*C2" },        // D2: 公式
    { (1, 2), "200" },           // B3
    { (2, 2), "3" },             // C3
    { (3, 2), "=B3*C3" },        // D3: 公式
    { (4, 0), "合计" },          // E1
    { (4, 1), "=SUM(D2:D3)" },   // E2: 范围求和的公式
};

spreadSheet.SetData(data);
```

**`SetData` 会自动处理**：

- 识别以 `=` 开头的公式并求值
- 调用级联重算，更新所有引用了被修改单元格的公式
- 记录撤销历史（如果启用了 UndoStack）

### 6.2 直接修改数据字典（高级用法）

```csharp
// 直接操作 Data 字典（绕过 SetData，不记录撤销历史）
spreadSheet.Data[(0, 0)] = "50";        // 设置 A1 的值

// 如果是大批量修改，完成后调用统一重算
spreadSheet.RecalculateAll();
```

### 6.3 统一重算：RecalculateAll

当通过直接操作 `Data` 字典批量修改数据后，调用此方法一次性刷新所有公式：

```csharp
// 批量修改数据（直接从数据库加载等场景）
foreach (var item in dbRecords)
{
    int col = item.ColumnIndex;
    int row = item.RowIndex;
    spreadSheet.Data[(col, row)] = item.Value;
}

// 一次性重算所有公式单元格
spreadSheet.RecalculateAll();
```

> **最佳实践**：批量修改数据时，先用直接赋值修改 `Data`，最后调用一次 `RecalculateAll()`。
> 
> 如果用 `SetData`，它内部会每个 key 触发一次级联重算，批量场景下会显得低效。

### 6.4 读取单元格值

```csharp
// 读取原始文本（含 = 前缀）
if (spreadSheet.Data.TryGetValue((0, 0), out string rawText))
{
    Console.WriteLine(rawText);  // "=SUM(A2:A10)" 或 "100"
}

// 读取公式单元格的缓存值
if (spreadSheet.ContentTable.FormulaCells.TryGetValue((0, 0), out CellData cellData))
{
    Console.WriteLine(cellData.CachedValue);  // 计算结果
    Console.WriteLine(cellData.Formula);      // "SUM(A2:A10)"
    Console.WriteLine(cellData.DisplayText);  // 显示文本
}
```

### 6.5 单独求值一个公式

```csharp
// 获取公式引擎
var engine = spreadSheet.FormulaEngine;

// 解析（不产生副作用）
var ast = engine.Parse("A1 + B1 * 2");

// 求值并注册依赖关系
var result = engine.Evaluate((0, 0), "A1 + B1 * 2");
// result.CachedValue → 计算结果
// result.Formula → "A1 + B1 * 2"
```

## 7. 依赖追踪与级联重算

### 7.1 工作原理

当你输入一个引用其他单元格的公式时，引擎会自动建立依赖关系：

```
A1 = 10
B1 = 20
C1 = =A1 + B1          ← C1 依赖 A1 和 B1
D1 = =C1 * 1.13        ← D1 依赖 C1
```

当你修改 A1 为 20 时，引擎会自动：

1. 查找所有依赖 A1 的公式（C1）
2. 用拓扑排序确保正确的重算顺序（C1 先算，D1 再算）
3. 更新所有受影响的单元格

**这个过程对用户完全透明，无需手动干预。**（之前修复的 bug 就是确保普通数据单元格修改时也能触发此机制。）

### 7.2 循环引用检测

如果公式引用了自己（或间接引用自己），引擎会抛出错误：

```
A1 = =A1 + 1            → #ERROR: Circular reference detected at A1
A1 = =B1                → A1 引用 B1
B1 = =A1                → #ERROR: Circular reference detected (A1→B1→A1)
```

### 7.3 手动控制

```csharp
// 手动触发某个单元格修改后的级联重算
var engine = spreadSheet.FormulaEngine;
var results = engine.CascadeRecalculate((0, 0));   // A1 被修改
// results 包含所有被重算的单元格及其新值

// 清除公式引擎的所有缓存（通常在重新加载数据时使用）
engine.Clear();
```

## 8. 错误处理

### 8.1 用户可见的错误

公式出错时，单元格会显示 `#ERROR: 错误信息`：

| 错误   | 示例             | 显示                                                                      |
| ---- | -------------- | ----------------------------------------------------------------------- |
| 未知函数 | `=UNKNOWN(1)`  | `#ERROR: Unknown function: 'UNKNOWN'`                                   |
| 循环引用 | `A1: =A1+1`    | `#ERROR: Circular reference detected at A1`                             |
| 参数不足 | `=ROUND(3.14)` | 不会报错（digits 有默认值）                                                       |
| 类型错误 | `=SQRT(-1)`    | `#ERROR: Error in function 'SQRT': SQRT requires a non-negative number` |

### 8.2 自定义函数中的错误处理

有两种做法：

```csharp
// 做法 1：抛出异常（会显示为 #ERROR）
spreadSheet.FormulaEngine.Functions.Register("SAFE_DIVIDE", args =>
{
    double divisor = Convert.ToDouble(args[1]);
    if (divisor == 0)
        throw new Exception("除数不能为零");
    return Convert.ToDouble(args[0]) / divisor;
});

// 做法 2：返回错误字符串（作为普通结果显示）
spreadSheet.FormulaEngine.Functions.Register("SAFE_DIVIDE2", args =>
{
    double divisor = Convert.ToDouble(args[1]);
    if (divisor == 0)
        return "#DIV/0!";
    return Convert.ToDouble(args[0]) / divisor;
});
```

> 推荐做法 1，因为 `FormulaEngine` 会统一捕获异常并格式化为 `#ERROR:` 前缀，便于用户识别。

### 8.3 错误隔离

一个公式报错**不会**影响其他无关公式的计算。依赖图中只重算受影响的节点。

## 9. 常见问题

### Q: 修改数据后公式不自动刷新？

**A:** 使用 `SetData` 方法会触发级联重算。如果直接操作 `Data` 字典，需要在修改后调用 `RecalculateAll()`。

### Q: SUM/AVERAGE 等范围函数返回 ERROR？

**A:** 请确保使用的是修复后的版本（之前存在 Lexer 的 bug）。公式如 `=SUM(B2:B4)` 应正常工作。

### Q: 自定义函数支持异步调用吗？

**A:** 公式求值是同步的，不支持 async/await。如果计算很重，建议在注册函数内使用缓存：

```csharp
private Dictionary<string, double> _calcCache = new();

spreadSheet.FormulaEngine.Functions.Register("HEAVY", ctx =>
{
    string key = string.Join(",", ctx.Args.Select(a => a?.ToString()));
    if (_calcCache.TryGetValue(key, out double cached))
        return cached;
    double result = HeavyComputation(ctx.Args);
    _calcCache[key] = result;
    return result;
});
```

### Q: 自定义函数能访问数据库或网络吗？

**A:** 技术上可以，但不推荐。公式求值是同步的，网络/数据库调用会阻塞 UI。建议在修改数据之前完成数据的预处理。

### Q: 如何把自定义函数参数的类型做强校验？

**A:** 在函数开头做手动校验：

```csharp
spreadSheet.FormulaEngine.Functions.Register("MYFUNC", args =>
{
    if (args.Count < 2)
        throw new Exception("MYFUNC 需要至少 2 个参数");
    if (!double.TryParse(args[0]?.ToString(), out double param1))
        throw new Exception("MYFUNC 第一个参数必须是数字");
    string param2 = args[1]?.ToString() ?? "";
    // ... 业务逻辑
});
```

### Q: 如何实现类似 Excel 的 OFFSET/INDIRECT 函数？

**A:** 使用上下文注册方式，通过 `ctx.GetCellValue(col, row)` 或 `ctx.GetValue("A1")` 读取动态位置的值：

```csharp
// 模拟 OFFSET(reference, rows, cols)
spreadSheet.FormulaEngine.Functions.Register("OFFSET", ctx =>
{
    // 从 ctx.Cell 计算偏移后的位置
    int offsetRow = ctx.Row + Convert.ToInt32(Convert.ToDouble(ctx.Args[0]));
    int offsetCol = ctx.Column + Convert.ToInt32(Convert.ToDouble(ctx.Args[1]));
    return ctx.GetCellValue(offsetCol, offsetRow);
});
```

## 附录：完整自定义函数示例

以下是一个工资计算的完整示例，展示如何将多个自定义函数组合使用：

```csharp
public void SetupPayrollFormulas(Spreadsheet sheet)
{
    var funcs = sheet.FormulaEngine.Functions;

    // 1. 社保计算（从配置表读取比例）
    funcs.Register("SOCIAL_SECURITY", ctx =>
    {
        double salary = Convert.ToDouble(ctx.Args[0]);
        // 从 A1 读取社保比例（假设 A1 = 0.105）
        double rate = Convert.ToDouble(ctx.GetValue("A1") ?? 0.105);
        return Math.Round(salary * rate, 2);
    });

    // 2. 个税计算（累进税率）
    funcs.Register("INCOME_TAX", ctx =>
    {
        double taxable = Convert.ToDouble(ctx.Args[0]);
        if (taxable <= 36000) return taxable * 0.03;
        if (taxable <= 144000) return taxable * 0.10 - 2520;
        if (taxable <= 300000) return taxable * 0.20 - 16920;
        return taxable * 0.25 - 31920;
    });

    // 3. 实发工资 = 基本工资 - 社保 - 个税
    funcs.Register("NET_PAY", ctx =>
    {
        double gross = Convert.ToDouble(ctx.GetValue("B" + (ctx.Row + 1)));
        double ss = Convert.ToDouble(ctx.GetValue("C" + (ctx.Row + 1)));
        double tax = Convert.ToDouble(ctx.GetValue("D" + (ctx.Row + 1)));
        return gross - ss - tax;
    });
}

// 使用 SetupPayrollFormulas 后，表格中的公式示例：
// A1: 0.105
// B2: 20000          (基本工资)
// C2: =SOCIAL_SECURITY(B2)        → 2100
// D2: =INCOME_TAX(B2-C2-5000)     → 个税
// E2: =NET_PAY()                  → 实发工资
```
